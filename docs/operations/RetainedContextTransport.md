# Owned retained-controller public context transport

The independent parent now launches one fixed retained-controller child under its
own actual process/job/pidfd fence. The guardian is outside the lifetime of that
child's job. The fixed child pins the same public source/entrypoint inputs,
verifies its actual self and parent process images/births, performs the existing
native public publication and keeps its original publication descriptors while
offering one fixed public image build context. No Docker command or service is
started by this transport.

The parent holds an independently prepared public reference bundle. It checks
the complete child context against its own bytes and deterministic fixed recipe,
not against a reference supplied over the channel. Native plan, manifest/probe,
base references, labels, timestamps, resource sizes, hashes and schemas are
bounded and exact. A wire image/container ID, runtime command, extra file, changed
tar byte or foreign manifest is rejected. The public base metadata in the
transport fixture is explicitly generated; it proves no registry availability
or actual image build. Future build admission must measure the fixed cached bases
and retain the guardian's own successful build/create replies.

Only a bounded startup header, length-prefixed offer/context, and one fixed
close-without-Docker frame are exchanged through owned anonymous pipes. Output,
stderr and payload lengths are bounded before admission; no generic command,
path, endpoint, secret or original-data channel exists. Exclusive flushed start
and ready records retain nonce consumption across replay/failure. Source, runtime,
reference and actual process identity checks bracket data admission. The parent
keeps the accepted context usable only while the actual child is live.

The fixed close frame closes all child publication descriptors before a bounded
closure receipt and normal process exit. The parent checks its own process fence
and exact output closure. Killing the actual controller after its offer prevents
further source use while the independent parent remains alive; the retained
transport cannot restart under the same consumed nonce. No resource deletion is
derived from these frames or records.

Portable contracts exercise the generated codec/admission and retained-record
boundaries on Windows and Linux. The Linux native publication fixture reuses its
already prepared public reference, then runs two actual retained-controller
children: graceful close and controller death after offer. The same 58 child
publication descriptors are held through offer, and the parent's independent 58
reference descriptors remain unchanged. A standalone native fixture uses the
shared public snapshot/tool/reference setup without repeating the old native
fault cases. Real Windows native controller transport is not claimed by portable
tests; the existing Windows process-fence contracts remain mandatory.

The post-offer death case occurs after the native publisher's own fence has
verified its members absent. General bootstrap/compiler subgroup escape after
an external kill, guardian/host death, disk rollback, partial/lost outputs and
full service recovery remain open. Linux process-group fencing does not prove
containment of escaped sessions. Unknown outcomes retain records and are never
reported as a completed image build, worker create or cleanup.

Next, keep this actual controller alive while the independent parent performs
the fixed verified public-context build, owns its complete immutable image and
stopped-copy receipts, returns checked readback for the retained typed bindings,
and creates the fixed sleep worker from its own image. Independent expiry/death
cleanup must then use only the guardian's own creation facts and fresh full-ID
inspection. Serialized preparation/transport reports are descriptive metadata,
not authority tokens. The retained 660-second sleep profile has no proven
thirty-second fallback; that fallback belongs only to the separate Python proof.

No original inputs, private PKI, provider, issuer, production token or VPS access
is added. Phase 7 and draft PR #2 remain open, including independent WORM/custody,
human/physical-Agent admission, PKI/revocation and full RPO/RTO.
