# Live four-input capture and one-use consumption

`historical.retained_service_use.use` connects the existing four-input reader to
a retained consumed-attempt record. It is a library for trusted host code and
has no root, reset, permission, Docker or command CLI. The legacy audit-only use
purpose and its reader remain separate.

Before capture it freezes the exact plan, roots, selection/manifest/checkpoint
and accepted CI/local-Sonar record bytes. It checks the four-input metadata
through the existing reader. A distinct exclusive, flushed attempt is retained
before source/runtime admission or any artifact open. Source, Python executable,
actual own image/birth, input-directory identity and record handles remain live.
The original 108-second operation clock is not restarted by capture or dispatch;
wall rollback and expiry also refuse a returned result.

Capture consumes its one slot before opening the four selected artifacts. Only
the same live object on its creating process/thread can pass the frozen serialized payload once to the callback
supplied by trusted host code. Callback errors, partial/lost responses, expiry or
oversized results consume that slot. Copied/foreign/closed objects cannot adopt
the live records or repeat capture. Reports do not reconstruct a capability.
There is no action or callback supplied by JSON.

The listed source hashes and pinned gate-record semantics are checked. This
does not authenticate the origin of those records, an existing user consent,
transitive loaded code/dependencies, a native consumer process or its returned
result. Local consumed records do not provide independent anti-rollback custody.
The image/probe/configuration commitments are frozen plan fields, not proof that
a native process actually used them.

The next required adapter must keep this context alive through the exact fixed
native consumer, independently bind its process/private transport and measured
image/configuration, and exercise that same route with generated data and the
existing recovery targets before any original artifact read. This library does
not yet make the original executor ready. Do not replace that work with an
unrelated generated-only service scope or infer launch authority from a PASS.

Portable tests use only generated files. They require real own process identity,
four-file capture, flushed pre-open consumption, frozen packets, refusal after
source/record/owner loss, original-clock expiry before/after capture or return,
and non-retry after capture/consumer failures. Existing consumed-record and
audit-only contracts remain regressions.

Original backups, credentials/private PKI, provider/identity material and VPS
are not used. General creator/guardian/daemon/host loss, original release/build/
configuration/key lineage, independent WORM/actors, human/physical Agent and
full recovery RPO/RTO remain open. Phase 7 and draft PR #2 stay open.
